# Healthcare Intelligence Engine

A simple, dependency-free Python base project for healthcare analytics.

## Features
- Patient model with automatic BMI calculation
- Vitals classification (BMI, blood pressure, glucose)
- Rule-based cardiac and diabetes risk scoring
- Symptom-to-condition matcher with emergency flags
- Drug interaction checker
- Cohort (population) analytics
- Text report generator with recommendations

## Run
    python healthcare_engine.py

Requires Python 3.8 or newer. No installation needed.
